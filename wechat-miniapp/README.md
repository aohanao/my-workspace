# 个人工作台微信小程序

这是一个轻量入口，点击后通过微信小程序的 `web-view` 打开现有移动端网页。网页原有的邮箱密码登录和云端数据同步继续由网页处理。

## 配置与预览

1. 当前已配置 `https://my-workspace-beta.vercel.app/`；如果网址变更，请修改 `config.js`。
2. 在[微信公众平台](https://mp.weixin.qq.com/)创建小程序，取得 AppID；把 `project.config.json` 里的 `touristappid` 替换为该 AppID。
3. 在小程序后台将工作台网址的域名配置为 **业务域名**，并按平台要求完成域名验证。
4. 用微信开发者工具导入本目录，预览并在真机上测试登录、导航、数据同步与文件操作。
5. 测试通过后，在微信开发者工具上传小程序代码，再到后台提交审核发布。

如果开发者工具中临时关闭域名校验，只能用于本地调试；正式发布仍需配置业务域名。`web-view` 内的网页与手机浏览器各自保存登录状态，首次进入需要重新登录。

当前项目仅提供网页入口，不新增微信登录，也不会改变现有 Supabase 权限或账户。
